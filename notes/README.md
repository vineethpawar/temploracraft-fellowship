# The course

Eight modules, about twenty hours. Modules 1, 2, 3, 6 and 8 are touched
in the workshop; the rest are here so the map is complete.

| # | Module | Hours | Status |
| --- | --- | --- | --- |
| 1 | Components, props, composition | 2 | |
| 2 | State, derived state, lifting | 3 | |
| 3 | Effects, cleanup, and avoiding them | 3 | |
| 4 | Data fetching, loading and error states | 3 | |
| 5 | Forms without a library | 2 | |
| 6 | Design systems and plyxui | 2 | |
| 7 | Performance: memo, keys, render counts | 2 | |
| 8 | Testing: Vitest and Playwright | 3 | |

Each module: a written note, a runnable exercise, and two problems with
answers.

The exercises in [../exercises](../exercises) map onto modules 1–4, 6
and 7 — start there, they are the same code you saw in the room.
