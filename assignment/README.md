# temploracraft Fellowship — assignment

A small resume editor. About 70% of it is built. You write four files.

## Setup

```bash
npm install
npm run dev
```

Read [TICKETS.md](./TICKETS.md), then open the four files in
`src/tickets/`. Each carries its own spec.

```bash
npm test           # unit tests, tickets 1, 2 and 4
npm run test:e2e   # behaviour tests, tickets 1 and 3
npm run check-types
```

## Submitting

1. **Use this template → Private.** Do not fork — a fork is public and
   anyone could read your work.
2. Add `@vineethpawar` as a collaborator.
3. Push. The grader runs and writes `SCORECARD.md`.
4. Write `REFLECTION.md` (200 words).
5. Send the repo URL.

## Rules

- Use AI freely. See TICKETS.md for what it will get wrong.
- Do not edit the tests. They are the specification.
- Do not edit files outside `src/tickets/` and `REFLECTION.md`.
